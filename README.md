# Hadi Barışalım ❤️

Hadi Barışalım, insanların küslüklerini sonlandırmalarına yardımcı olmak amacıyla geliştirilmiş modern bir web uygulamasıdır.

## 🚀 Özellikler

- 🎨 Modern ve şık kullanıcı arayüzü
- 📱 Tam responsive tasarım
- ⚡ Hızlı ve optimize edilmiş performans
- 🌙 Kullanıcı dostu deneyim
- ✨ Akıcı animasyonlar
- 🔒 Temiz ve sürdürülebilir kod yapısı

## 🛠️ Kullanılan Teknolojiler

- Next.js
- React
- TypeScript (kullanıyorsan)
- Tailwind CSS
- Vercel

## 🎯 Amaç

Bu proje, insanların duygularını daha kolay ifade edebilecekleri ve barışma süreçlerini destekleyen sade ve etkileyici bir platform sunmayı amaçlamaktadır.
